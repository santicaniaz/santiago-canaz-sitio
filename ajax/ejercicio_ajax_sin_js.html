Ejercicio de AJAX (versión sin JavaScript)

El ejercicio original hace una petición AJAX al archivo que se escribe en el campo URL y muestra el contenido, los estados de la petición, el código de estado y las cabeceras HTTP. Como eso necesita JavaScript, en esta página está el mismo resultado ya cargado, para la petición al archivo recurso_prueba.txt (el enlace abre el archivo directamente, sin JavaScript).

Contenidos del archivo:

Este es un archivo de prueba para el ejercicio de AJAX.
Si ves este texto dentro del recuadro "Contenidos del archivo",
la petición AJAX funcionó correctamente.

Podés probar también con ejercicio_ajax.html como URL,
para ver cómo trae su propio código fuente.

Estados de la petición:

  1. OPENED (conexión establecida con el servidor)
  2. HEADERS_RECEIVED (cabeceras de la respuesta recibidas)
  3. LOADING (descargando la respuesta)
  4. DONE (petición finalizada)

Código de estado:

200 OK

Cabeceras HTTP de la respuesta del servidor:

accept-ranges: bytes
access-control-allow-origin: *
cache-control: max-age=600
content-encoding: gzip
content-length: 211
content-type: text/plain; charset=utf-8
date: Wed, 11 Nov 2026 20:50:08 GMT
last-modified: Wed, 11 Nov 2026 19:20:55 GMT
server: GitHub.com
vary: Accept-Encoding
via: 1.1 varnish
x-cache: HIT

Si el archivo no existe

Si se pide un archivo que no está en el servidor, por ejemplo no-existe.txt, la petición pasa por los mismos cuatro estados pero el código de estado es 404 Not Found, y en el recuadro de contenidos aparece la página de error que devuelve el servidor.
