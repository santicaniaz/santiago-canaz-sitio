Accesibilidad

Este sitio fue revisado para cumplir el nivel de conformidad AA de las Pautas de Accesibilidad al Contenido en la Web 1.0 (WCAG 1.0) del W3C. Entre otras cosas:

  • Todas las páginas usan HTML válido (XHTML 1.0 Strict) y una hoja de estilos externa.
  • Las imágenes tienen un texto alternativo que las describe.
  • Los tamaños de letra y las medidas están en unidades relativas, por lo que se pueden agrandar desde el navegador.
  • Los colores de texto y fondo tienen contraste suficiente, y los enlaces se distinguen también por el subrayado.
  • El menú es el mismo en todas las páginas y hay un enlace para saltar directo al contenido.
  • Las tablas de datos tienen título, resumen y encabezados asociados a cada celda.
  • Los campos del formulario tienen etiquetas asociadas.
  • No se abren ventanas nuevas sin aviso ni hay contenido que se mueva o parpadee.
